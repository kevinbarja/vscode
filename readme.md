# VS CODE Shortcuts
| Command      | Description |
| ----------- | ----------- |
| ``ctrl + e or ctrl + p``      | Quick Open (search files)    |
| ``ctrl + shift + p``   | Command Palette      |
| ``ctrl + h``     | Replace     |
| ``ctrl + alt + enter``     | Replace all |
| ``ctrl + g``     | Go to line |
| ``shit + alt + F``     | Format document |
| ``ctrl + T``     | Focus on terminal view [(see.)](https://youtu.be/Dk5rpfdVnn0?list=PLm43N15wzkBOKnYigHPpxjYNBHujXPOj6&t=163)|
| ``ctrl + 1``     | Focus first editor group |
| ``ctrl + n``     | New untitled file |
| ``ctrl + K  M``     | Change language mode |
| ``ctrl + P arrow up``     | Toggle maximized panel [(see.)](https://youtu.be/Dk5rpfdVnn0?list=PLm43N15wzkBOKnYigHPpxjYNBHujXPOj6&t=295)|
| ``ctrl + shift +  5``     | Terminal: Split terminal |

# Dotnet commands
| Command      | Description |
| ----------- | ----------- |
| ``dotnet --info``      | Version of SDK      |
| ``dotnet new list``      | Scaffoldings     |
| ``dotnet new gitignore``      | Add gitignore     |
| ``dotnet new console -f net7.0 --name "TestUI"``     | Create a console app     |
| ``dotnet new classlib -f net7.0 --name "HelperLib"``     | Create a library     |
| ``dotnet add TestUI/TestUI.csproj reference HelperLib/HelperLib.csproj``     | Add reference     |
| ``dotnet add package Dapper``    | Add package     |

# Claude Code commands
| Command      | Description |
| ----------- | ----------- |
| ``claude``      | Start an interactive session in the current folder      |
| ``claude "query"``      | Start a session with an initial prompt      |
| ``claude -p "query"``      | Run a single query and exit (print mode)      |
| ``claude -c``      | Continue the most recent conversation      |
| ``claude -r``      | Resume a previous conversation (picker)      |
| ``claude update``      | Update Claude Code to the latest version      |
| ``claude mcp``      | Configure MCP servers      |
| ``/help``      | Show help and available commands      |
| ``/init``      | Create a CLAUDE.md file with project documentation      |
| ``/clear``      | Clear the conversation history      |
| ``/compact``      | Summarize the conversation to free up context      |
| ``/model``      | Change the model      |
| ``/config``      | Open settings      |
| ``/permissions``      | View or change tool permissions      |
| ``/memory``      | Edit CLAUDE.md memory files      |
| ``/review``      | Review a pull request      |
| ``/cost``      | Show token usage for the session      |
| ``@file``      | Reference a file in your prompt      |
| ``!command``      | Run a shell command directly (bash mode)      |
| ``shift + tab``      | Switch permission mode (e.g. auto-accept, plan)      |
| ``esc``      | Stop Claude while it is working      |
| ``esc esc``      | Go back to a previous message      |
| ``ctrl + c``      | Cancel input / exit      |
